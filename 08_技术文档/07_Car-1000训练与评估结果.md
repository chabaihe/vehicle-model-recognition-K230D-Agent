# Car-1000 训练与评估结果（主线 B）

> 数据集：Car-1000（1000 类中国车型 / 140,267 张）
> 模型：ResNet-50 @ 224×224，迁移学习 + 类别加权损失 + 余弦退火
> 训练：15 epoch / **97.4 分钟**（RTX 4060 Laptop 8 GB）
> **最终成绩：测试集 Top-1 = 86.77% ｜ Top-5 = 98.16% ｜ 车辆大类 = 98.24%**

---

## 二、分层评估（★ 本阶段最有价值的分析）

Car-1000 自带**三级层次标签**（大类 → 细分类 → 英文），因此可以同时评估"细粒度"与"粗粒度"两个层面。

### 2.1 按车辆大类

| 大类 | 样本数 | 类别数 | **Top-1** |
|---|---|---|---|
| **SUV** | 12,635 | 422 | **0.9858** |
| **轿车** | 9,193 | 298 | **0.9825** |
| 卡车 | 2,439 | 101 | 0.9791 |
| MPV | 1,713 | 69 | 0.9790 |
| 轻客 | 802 | 32 | 0.9738 |
| 跑车 | 1,291 | 44 | 0.9737 |
| 微面 | 780 | 34 | 0.9667 |
| **全部** | 28,853 | 1,000 | **0.9824** |

### 2.2 层次混淆矩阵（7×7）—— 近似对角

```
真实\预测   MPV   SUV   卡车  微面  跑车  轻客  轿车
MPV        98     1     0     0     0     0     1
SUV         0    99     0     0     0     0     1
卡车        0     1    98     0     0     0     0
微面        0     0     1    97     0     1     0
跑车        0     1     0     0    97     0     2
轻客        1     0     0     1     0    97     0
轿车        0     1     0     0     0     0    98
```

**关键结论**：**细粒度 86.77% → 大类 98.24%（提升 11.5 个百分点）**。

这说明：**模型几乎从不把 SUV 认成轿车**，它的错误**全部发生在同一大类内部的细分车型之间**。这是"分层分类"价值的直接证据。

## 三、混淆结构分析（★ 最强的发现）

### 3.1 最易混淆的 10 对

| 错误次数 | 真实 → 被误认成 | 差异类型 |
|---|---|---|
| **19** | 领克_领克01 → 领克_领克01 **PHEV** | **仅动力形式** |
| **18** | 奥迪_奥迪S5 → 奥迪_奥迪A5 | 性能版→普通版 |
| **18** | 长安跨越_跨越王X1 → 跨越王X1 **EV** | **仅动力形式** |
| **18** | 沃尔沃_沃尔沃XC90 → 沃尔沃XC90 **RECHARGE** | **仅动力形式** |
| **17** | 丰田_广汽丰田bZ4X → 丰田_一汽丰田bZ4X | **仅合资厂不同** |
| **17** | 奥迪_奥迪e-tron GT → 奥迪**RS** e-tron GT | 性能版 |
| **17** | 奥迪_奥迪A5 → 奥迪_奥迪S5 | 普通版→性能版 |
| **16** | 路虎_揽胜极光 → 揽胜极光**PHEV** | **仅动力形式** |
| **16** | 奥迪_奥迪A7 → 奥迪_奥迪A7**L** | **仅轴距加长** |
| **16** | 丰田_一汽丰田bZ4X → 丰田_广汽丰田bZ4X | **仅合资厂不同** |

### 3.2 决定性发现一：**100% 的混淆都发生在同品牌内部**

| 归类 | 错误次数 | 占比 |
|---|---|---|
| **同品牌内部** | **1,146** | **100.0%** |
| 跨品牌 | 0 | 0.0% |

**（统计前 100 对混淆的总错误次数）**

**也就是说：模型从不把比亚迪认成特斯拉，也从不把五菱认成长安。它已经完全学会了"品牌级"的视觉特征。**

### 3.3 决定性发现二：**主要失败模式是"同款车不同动力形式"**

观察上表，**10 对里有 5 对只差动力形式**（PHEV / EV / RECHARGE），另外还有差在**合资厂**（一汽丰田 vs 广汽丰田）、**轴距**（A7 vs A7L）、**性能调校**（S5 vs A5、RS e-tron GT）。

**这个发现与选题动机相互印证**——当前中国市场新能源车占比高：

> **电动版、插混版与燃油版往往是同一款车的外观，仅靠摄像头视觉几乎无法区分。**

**这是一个有实际意义的结论**：若目标是"识别车辆类型"，这类混淆在工程上可接受（它们本来就是同一款车）；但若目标是"精确到具体配置版本"，则需要引入更多信息（如车牌、车标细节高分辨率图像）。

### 3.4 每类准确率分布

- **中位 92.3%**，多数类别表现良好；
- 分布明显左偏 —— 少数类别准确率很低，拉低了平均。

**最差的 8 个类别**：

| 准确率 | 类别 | train 样本数 |
|---|---|---|
| 0.118 | 长安跨越_跨越星V3 | 46 |
| 0.125 | 奥迪_奥迪S7 | 44 |
| 0.143 | 依维柯_依维柯聚星 | **16** |
| 0.192 | 五十铃_翼放ES5 | 78 |
| 0.192 | 五菱汽车_五菱荣光新卡 | 78 |
| 0.200 | 五菱汽车_五菱EV50 | **12** |
| 0.211 | 北汽制造_王牌M7 | 52 |
| 0.241 | 长安跨越_跨越星V5 EV | 84 |

**注意**：最差类别里既有少样本的（16、12 张），也有样本不少但易混淆的（78、84 张）。

## 四、少样本类别表现（对应 31:1 不均衡）

| 训练样本数档位 | 类别数 | 平均 Top-1 |
|---|---|---|
| **0–20 张** | 39 | **0.7451** |
| 20–50 张 | 105 | 0.7995 |
| 50–100 张 | 481 | 0.8434 |
| **100–200 张** | 375 | **0.8971** |

**单调递增，符合预期**：样本越多，准确率越高。

**但要注意一个重要事实**：即使只有 **0–20 张**训练图，平均准确率仍有 **74.51%** —— **这证明迁移学习（ImageNet 预训练）在少样本场景下非常有效**，是最有价值的工程结论之一。

**改进方向**：对 0–50 张的 144 个类别（占 14.4%）做**数据增强加强**或**专门采样**，有望提升整体准确率。

## 五、训练与资源实测

| 指标 | 数值 |
|---|---|
| 训练集 / 验证集 / 测试集 | 83,756 / 27,658 / 28,853 |
| 总训练耗时 | **97.4 分钟**（15 epoch） |

**显存结论**：1000 类 + ResNet-50 + 224px 只占 **3.05 GB**，8 GB 完全充裕。

| | 主线 A：Stanford Cars | **主线 B：Car-1000** |
