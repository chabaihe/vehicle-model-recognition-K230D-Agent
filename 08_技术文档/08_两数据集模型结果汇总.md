## 一、研究概述

本项目分两个阶段完成车辆型号识别：

| 阶段 | 数据集 | 类别数 | 定位 |
|---|---|---|---|
| 阶段一 | Stanford Cars | 196 类 | 验证方法可行，建立精度基线 |
| **阶段二** | **Car-1000** | **1000 类** | **贴近中国道路场景，可上硬件** |

**为什么要换数据集？**
Stanford Cars 只覆盖 **1991–2012 年的美国车型**，中国品牌类别数为 **0**。用它训练出来的模型，认不出中国路上的车。因此改用 **Car-1000**（源自中国"懂车帝"，覆盖 1960s–2020s，含五菱、比亚迪、长安、吉利等中国品牌）。

## 二、两个数据集对比

| 项目 | Stanford Cars | **Car-1000** |
|---|---|---|
| 类别数 | 196 | **1,000** |
| 图片总数 | 16,185 | **140,267** |
| 训练 / 验证 / 测试 | 8,144 / — / 8,041 | 83,756 / 27,658 / 28,853 |
| 品牌数 | — | **166** |
| 年份覆盖 | 1991–2012 | **1960s–2020s** |
| 数据来源 | 美国车市 | **中国"懂车帝"** |
| 中国品牌 | **0** | **五菱 / 比亚迪 / 长安 / 吉利 / 奇瑞 / 福田…** |
| 标签形式 | 英文车型名 | **中文"品牌_车型"+ 车辆大类** |
| 标签层次 | 无 | **有（7 大类 / 21 细分类）** |
| 每类样本（中位） | 42 张 | 92 张 |
| 类别不均衡比 | 2.8 : 1 | 31 : 1 |

**关键优势**：Car-1000 的标签就是**中文品牌 + 具体车型**，且自带**车辆大类**标签，既能做细粒度识别，也能做分层评估。

## 三、两个模型的训练结果

统一配置：**ResNet-50 · 224×224 · 迁移学习 · 类别加权损失 · 余弦退火**

| 指标 | Stanford Cars（196 类） | **Car-1000（1000 类）** |
|---|---|---|
| **测试集 Top-1** | **91.33%** | **86.77%** |
| **测试集 Top-5** | **98.46%** | **98.16%** |
| 随机猜测基线 | 0.51% | **0.10%** |
| 训练轮次 | 12 epoch | 15 epoch |
| 训练耗时 | 28.6 分钟 | 97.4 分钟 |
| 峰值显存 | 1.69 GB | **3.05 GB** |
| 每 epoch 耗时 | 约 2.4 分钟 | 约 6 分钟 |

**说明**：两个数据集的类别数与数据规模不同，**绝对精度不能直接比较**。Car-1000 用 5 倍的数据量、5 倍的类别数，仍达到 86.77%，说明方法有效。

## 四、Car-1000 的分层评估（核心亮点）

Car-1000 自带**车辆大类**标签，因此可以同时评估两个层次：

| 层次 | 类别数 | 准确率 |
|---|---|---|
| 细粒度（具体车型） | 1,000 | 86.77% |
| **车辆大类** | **7** | **98.24%** |

**大类准确率比细粒度高出 11.5 个百分点。** 这说明模型几乎不会把 SUV 认成轿车，它的错误全部发生在**同一大类内部的相似车型**之间。

| 车辆大类 | 类别数 | 准确率 |
|---|---|---|
| SUV | 422 | 98.58% |
| 轿车 | 298 | 98.25% |
| 卡车 | 101 | 97.91% |
| MPV | 69 | 97.90% |
| 轻客 | 32 | 97.38% |
| 跑车 | 44 | 97.37% |
| 微面 | 34 | 96.67% |

## 五、模型"错在哪里"（混淆结构分析）

分析最严重的 100 组误认，得到两个结论：

| 结论 | 数据 |
|---|---|
| **100% 的误认都发生在同品牌内部** | 同品牌 1146 次，跨品牌 **0 次** |
| 主要失败模式是**同款车不同动力形式** | 前 10 对里有 5 对只差 PHEV / EV / RECHARGE |

**典型误认案例**：

| 真实车型 | 被误认成 | 差异 |
|---|---|---|
| 领克01 | 领克01 **PHEV** | 仅动力形式 |
| 长安跨越 跨越王X1 | 跨越王X1 **EV** | 仅动力形式 |
| 沃尔沃 XC90 | XC90 **RECHARGE** | 仅动力形式 |
| 奥迪 S5 | 奥迪 A5 | 性能版 → 普通版 |
| 丰田 bZ4X（广汽） | 丰田 bZ4X（一汽） | 仅合资厂不同 |

**这说明**：模型对"品牌"的判断几乎不出错，输在**同品牌极相似车型**的区分上。而**电动版/插混版与燃油版外观基本相同**，仅靠摄像头视觉很难分辨。

**两个数据集给出同一规律**：Stanford Cars 的同品牌误认占 87.5%，Car-1000 占 100%。

## 六、少样本类别的表现

Car-1000 类别不均衡达 31:1，按训练样本数分档统计：

| 训练样本数 | 类别数 | 平均准确率 |
|---|---|---|
| 0–20 张 | 39 | 74.51% |
| 20–50 张 | 105 | 79.95% |
| 50–100 张 | 481 | 84.34% |
| 100–200 张 | 375 | 89.71% |

**即使只有 0–20 张训练图，平均准确率仍有 74.51%**，说明 ImageNet 预训练带来的迁移学习非常有效。

## 七、视角条件说明（重要）

训练数据（Car-1000）来自汽车网站，图片以**正面或侧前方约 45°视角**为主。因此模型的判别能力建立在"**能看到车头特征**"这个前提上——车灯、进气格栅、车标等最具辨识度的部件都集中在这个区域。

**已知的适用边界**：

| 视角条件 | 预期表现 | 原因 |
|---|---|---|
| 正面 / 侧前方 45°（与训练一致） | 正常（实测 Top-1 86.77%） | 与训练分布一致 |
| **正侧面（90°）** | **明显下降** | 车头特征全部不可见 |
| 俯视 / 极端角度、严重遮挡、夜间 | 明显下降 | 超出训练分布 |

**结论**：模型**不适合**正侧面视角的识别。这是数据集视角决定的固有边界，不是模型缺陷。

**后续实测计划**：补充拍摄**正常角度**（正面、侧前方）的真实车辆照片，重新做跨域测试并给出正式结果。测试思路与抽样方案见 [`16_对照实验方案.md`](<16_对照实验方案.md>)，数据齐备后可直接运行。

## 十、总结

**完成的工作**：
1. 在 Stanford Cars 上建立精度基线（196 类，Top-1 91.33%）
2. 发现老数据集的局限（止步 2012 年、无中国品牌）
3. 改用 Car-1000 重新训练（1000 类，Top-1 86.77%）
4. 利用层次标签做分层评估（车辆大类 98.24%）
5. 分析混淆结构（100% 集中在同品牌）
6. 实现电脑端识别工具（8/8 正确）
7. 打通端侧部署链路（对拍一致率 100%）

**主要局限**：
- **视角受限**：训练数据以正面/侧前方 45° 为主，**正侧面视角不适用**（详见第七节）
- 类别不均衡（31:1）导致少样本类别精度偏低
- 端侧部署尚未在硬件上实测

**改进方向**：
- 补充**正常角度**（正面、侧前方）的真实车辆照片，完成正式跨域测试
- 先裁剪车辆区域再分类，减少背景干扰
- 设置**置信度阈值**：低于阈值时只报车辆大类，不强行猜测具体车型
- 若需支持侧身视角，需在训练集中加入侧身样本
